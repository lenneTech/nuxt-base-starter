The root `CHANGELOG.md` is auto-generated by `standard-version` on each release and is NOT formatted in a style oxfmt accepts — it was a standing failure in the root `format:check` (which scans the whole repo). A `.prettierignore` at repo root (oxfmt reads `.gitignore` and `.prettierignore` by default) excludes `CHANGELOG.md` so `pnpm run format:check` stays green across releases.

**Why:** Added 2026-05-24. Reformatting the generated CHANGELOG would just recur on the next `standard-version` release, so excluding it is the durable root-cause fix rather than a one-time reformat.

**How to apply:** Do not reformat or remove `CHANGELOG.md` from the ignore. If a future maintenance run sees the root format gate failing only on CHANGELOG.md, confirm `.prettierignore` still lists it. See [[project-structure]] for the two-package check-script layout.
